# Recording checklist

- Use only the synthetic cases in `shared/sample-cases.json`.
- Hide browser bookmarks, account avatars, Firebase project IDs, debug tokens, and notifications.
- Record one real `ON_DEVICE` run and one real `IN_CLOUD` fallback where possible.
- Keep the inference-source badge visible for at least three seconds.
- Show both Web and Android functioning.
- Do not present synthetic demo mode as a live AI result.
- Keep the final edit at or below 3:00.
- Export 1080p H.264 with clear English voice-over.
- Add English subtitles and verify them after the public YouTube upload.
- Put the public app URL and repository URL in the video description.
